## What that means in practice

**Allowed** — using the skill, forking it, modifying it, building on it, and saying so: *"built
with opsinist"*, *"a fork of opsinist"*, *"opsinist-compatible"*.

**Not allowed** — using the name or the mascot for a fork or a derivative **in a way that suggests
it is this project**, or that this project endorses it. Rename your fork; that is the whole ask.

**Ask if unsure.** The line is about confusion, not control: the point is that someone
encountering the name knows which thing they are looking at.
